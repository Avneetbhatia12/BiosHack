# data/ (local only, never committed)

Put your **private** copy of the hackathon clips here, for example:

```
data/
  clips/        full-resolution MP4s
  clips_480p/   optional downscaled copies (PS3 uploads them instead of full resolution)
  MANO_RIGHT.pkl   (download it yourself from https://mano.is.tue.mpg.de after accepting the licence)
```

Everything in this folder except this README is gitignored. The footage belongs to the company that recorded it:
do not upload it anywhere public, and delete every copy when the event ends. See [docs/data_policy.md](../docs/data_policy.md).
